## 2. Secrets & Credential Exposure Audit

- **Next.js Production Bundle Inspection:** Automated grep across `buyer-web/.next/` static JavaScript chunks confirmed **ZERO** `service_role` keys, private JWT secrets, or administrative credentials in client assets.
- **Flutter APK & Dart Defines:** Sensitive credentials (`SUPABASE_URL`, `SUPABASE_ANON_KEY`) are passed strictly via compile-time `--dart-define`. Log masking (`::add-mask::`) is enforced in `.github/workflows/seller-app-ci.yml`.
- **Git Commit History:** Checked git log. No secret keys or credentials have been committed.

---

## 3. Public Projection & Column Exposure Verification

- `profiles` table: Direct SELECT revoked from `anon`. Public storefront data served exclusively via `public_seller_storefronts` view. Private seller phone number (`phone_number`) and return address (`return_address`) are strictly concealed.
- `products` table: Public catalog served via `public_products_catalog` view. Column `reserved_by_order_id` is completely masked, preventing competitors or scrapers from enumerating customer order IDs.
- `orders` table: Direct table query by anonymous buyers is blocked by RLS unless authenticated via `get_order_by_token(order_token)` RPC.
